Le Code de l'Échafaud

Un joueur est enfermé dans une pièce se remplissant de gaz mortel. L'autre possède la clé.

  • 🟢 : Lettre bonne et bien placée.
  • 🟡 : Lettre dans le mot, mais mal placée.
  • 🔴 : Lettre absente du mot.

Règles : 5 essais maximum. Si le joueur trouve : +3 Pts. S'il échoue : +3 Pts pour le Maître.
